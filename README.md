# Pose Sculptor

建築設計・パース作成のための、ミニマルで高品質な2D添景（フィギュア）生成ツール。

## 📂 ファイル構成
- `index.html`: アプリケーション本体
- `css/style.css`: UI/デザイン（スクロールバー非表示設定済み）
- `js/data.js`: **ポーズデータ（SVG Path）専用ファイル**
- `js/main.js`: アプリケーション・ロジック
